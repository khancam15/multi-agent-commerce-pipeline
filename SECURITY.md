# Security policy

## Supported versions

Security fixes are maintained on the default branch. Use the latest revision before reporting a problem.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner, khaneilcampbell. Use GitHub's **Report a vulnerability** option in the Security tab when available. If it is unavailable, contact the maintainer through an existing private channel before sharing details.

Do not publish credentials, personal data, exploit details, or sensitive logs in public issues or pull requests. Include the affected revision, impact, and minimal reproduction steps in your private report. Redact secrets and personal information.

Please allow time for investigation and coordinate disclosure with the maintainer. No response-time guarantee is currently offered.

## Safe testing

Test only systems and accounts you own or are authorized to assess. Use test data and isolated environments; do not target production services, customer accounts, or third-party systems.
